Fitness Tracker Pro (Full-Stack SaaS)

A robust full-stack CRUD application for tracking strength training metrics. Built with a Python FastAPI backend and a reactive vanilla JavaScript frontend, featuring a custom Dark Mode UI and persistent SQL storage.

 Features
 Full CRUD Operations: Create, Read, Update, and Delete workout logs in real-time.
RESTful API: Engineered with **FastAPI** (Python) and **Pydantic** for rigorous data validation.
Persistent Database: Integrated **SQLite** with **SQLAlchemy ORM** for reliable relational data management.
Modern UI: Responsive "Dark Mode" interface built with CSS3 Flexbox and Vanilla JS (ES6+).
Cross-Platform DevOps: Includes **Bash scripts** (`entrypoint.sh`) for automated Linux deployment and PowerShell workflows for Windows.

Tech Stack
Backend: Python, FastAPI, SQLAlchemy, Uvicorn
Frontend: JavaScript (ES6), HTML5, CSS3
Database:SQLite (SQL)
Tools: Git, GitHub, Postman, VS Code
